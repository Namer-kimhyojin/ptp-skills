# 양식 계약

제공된 HWPX 양식의 작업 계약이다. 새 양식이 제공되면 새 양식의 구조를 우선한다.

## 회의록 양식

- 제목: `회  의  록`
- 필드: `{{회의명}}`, `{{회의일자}}`, `{{시작시간}}`, `{{종료시간}}`, `{{회의장소}}`, `{{내부참석인원}}`, `{{내부참석자}}`, `{{내부참석인원-1}}`, `{{외부참석인원}}`, `{{외부참석자}}`, `{{외부참석인원-1}}`, `{{회의비}}`, `{{다과비}}`, `{{합계}}`
- 내용 영역: `❑ 회의 결과`로 시작하는 고정 높이 셀
- 기본 형태: A4 1쪽

내용 셀은 표 행·열·병합을 유지한다. 한 쪽을 넘길 위험이 있으면 알린다. 본문과 지출 표의 회의비·다과비·합계는 모순되지 않아야 한다.

## 방명록 양식

- 열: 순번, 소속, 직위, 성명, 서명
- 데이터 행 10개, 표 높이 208mm, 머리행 포함 11행 (58961 HWPUNIT: 5361 + 5360 × 10)
- 서명 머리글 13pt
- 용지: A4 세로, 상·하·좌·우 15mm, 머리말·꼬리말 10mm, 제본 0mm (`4252`, `2835`, `0` HWPUNIT)
- 10명을 넘으면 같은 표를 새 페이지에 이어 붙이고 연번은 11부터 잇는다
- **서명 열은 빈칸**

여백이 달라졌으면 `scripts/set_hwpx_page_margins.py`로 여백만 교정한다.

## 지출증빙서 양식

- 제목: `지 출 증 빙 서`
- 필드: `{{지출항목}}`, `{{예산과목}}`, `{{사용금액}}`, `{{사용처}}`, `{{사용일자}}`
- 하단 큰 셀: 영수증 이미지
- 영수증 1건당 1쪽

## 보존해야 하는 HWPX 요소

`charPrIDRef`, `paraPrIDRef`, `borderFillIDRef`, `cellSz`, `cellMargin`, `cellSpan`, `rowSpan`, `secPr`를 가능한 한 양식 그대로 유지한다. 텍스트가 길어져도 페이지 구조나 표 행을 임의로 재설계하지 않는다.

# 브랜드·권리·사실 검토

## 현재 상태

테오·피오 v1.2 마스터 시트는 사용자 승인 제작 앵커로 잠겼다. 사용자 제공 CI 이미지는 `assets/asset-manifest.json`에 `review_only`로 남아 있으며, 기관 CI 가이드, 생성 결과의 소유권과 기관 게시 권한은 작업별로 아직 확인해야 한다.

## 공식 사용 전 확인

1. 캐릭터 원안·기준 이미지·생성 결과의 소유자와 수정·2차 이용 범위
2. 기관 명칭·로고·상표의 사용 권한과 승인 담당자
3. 공식 팔레트, 보호 여백, 금지 용례와 지정 글꼴 라이선스
4. 이미지 생성 도구의 상업 이용 및 입력 데이터 보존·학습 조건
5. 게시 채널과 발주처의 AI 사용 공개 정책
6. 이미지에 포함된 사실·통계·일정·절차의 출처, 확인일과 검토자
7. 실존 인물의 얼굴·성명·음성 사용 시 동의 범위

미확인 항목을 `cleared`로 표시하지 않는다. 검토용 시안에는 `검토용`, `예시`, `확인 필요`를 명시하고 외부 공개를 자동 수행하지 않는다.

## 사실 표현

정책·지원사업·모집·일정·금액·대상·연락처는 카드 또는 포스터 요소 ID와 출처를 연결한다. 최신성 있는 항목은 확인일과 유효기간을 기록한다. 출처가 없으면 확정 문구로 게시하지 않는다.

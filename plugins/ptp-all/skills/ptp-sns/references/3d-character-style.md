# 테오·피오 3D 이미지 생성 기준

이 기준은 실제 메시·리깅 파일이 아니라, AI 이미지 생성에서 반복 가능한 3D 캐릭터 렌더링을 만들기 위한 계약이다. 캐릭터 정체성은 기존 승인 가이드와 v1.2 마스터 시트가 우선하며, 3D 시트는 입체 볼륨·재질·조명만 보완한다.

## 기준 자산

- 테오: `assets/characters/3d/teo-3d-style-sheet-v1.0.png`
- 피오: `assets/characters/3d/pio-3d-style-sheet-v1.0.png`
- 두 캐릭터 함께: `assets/characters/3d/teo-pio-3d-family-sheet-v1.0.png`
- 기계 판독 규격: `assets/characters/3d/3d-style-spec-v1.0.json`
- 승인 포즈 참조: `assets/characters/3d/poses/pose-library.json`
- 재사용 프롬프트: [3d-generation-prompts.md](3d-generation-prompts.md)

세 시트는 2026-09-03 사용자 승인으로 `approved`, `three_d_style_set`은 `locked` 상태다. 이후 생성 결과는 이 기준을 사용하며 스타일을 바꾸려면 새 버전과 재승인이 필요하다.

## 참조 우선순위

1. 승인 v1.0 가이드: 머리 실루엣과 기본복
2. 승인 v1.2 마스터 시트: 시점·표정·가슴 문자·2.7등신과 체형
3. 3D 스타일 시트: 입체 두께·표면 재질·중성 조명과 렌더링 완성도

단독 등장에는 해당 캐릭터의 승인 2D 앵커와 3D 개별 시트를 함께 넣는다. 둘이 함께 등장하면 두 승인 2D 앵커와 3D 패밀리 시트를 사용한다. 먼저 승인 포즈 라이브러리에서 목적에 맞는 포즈를 재사용하며, 해당 PNG는 체크보드가 포함된 AI 참조 이미지이지 투명 합성 레이어가 아니다. 3D 시트나 포즈가 기존 승인 기준과 충돌하면 기존 승인 기준을 우선한다.

## 3D 렌더링 언어

- 고급 애니메이션용 기관 마스코트에 가까운 둥근 소프트 비닐 조형
- 얼굴은 따뜻한 백색 무광 폴리머, 기본복은 반무광 백색 소재와 거의 보이지 않는 미세 직물 결
- 파랑·주황 머리와 배색은 절제된 새틴 광택, 밑창은 고무 질감
- 금속성은 사용하지 않고 유리처럼 번쩍이는 강한 반사도 피한다.
- 조명은 부드러운 중성 주광색 3점 조명, 약한 명암·은은한 환경 차폐·분명한 접지 그림자
- 기준 시트는 정투영에 가까운 50~70mm 시야를 사용하고 극단적 광각과 원근 왜곡을 피한다.

## 변하지 않는 값

- 테오·피오 모두 약 2.7등신, 같은 어깨 폭·둥근 몸통 부피·팔다리 굵기·손·신발 크기
- 피오를 더 가늘거나 길게 만들지 않는다.
- 테오는 승인된 파란 비대칭 보브/물결형 머리, 피오는 승인된 주황 불꽃/물방울형 머리를 유지한다.
- 화면 기준 오른쪽 가슴 상단의 작은 `T/P`만 허용한다. 중앙 대형 문자와 머리 표식은 금지한다.
- 승인된 흰색 일체형 기본복과 파랑·주황 측면 패널·손목 배색·색상 밑창을 유지한다.
- 재킷, 네이비 바지, 벨트, 별도 장갑, 큰 손목 장치, 추가 로고를 만들지 않는다.

## 생성 프롬프트 조립

프롬프트에는 `same approved character`, `premium rounded soft-vinyl animated mascot`, `same 2.7-head proportions`, `neutral three-point daylight`, `small chest T or P only`, `no head mark`, `no costume redesign`을 작업 문맥에 맞게 포함한다.

단독·동시 등장용 전체 템플릿은 [3d-generation-prompts.md](3d-generation-prompts.md)를 사용한다.

배경·소품·포즈는 콘텐츠에 맞게 바꿀 수 있지만 재질과 캐릭터 비율은 유지한다. 실사 장면에 합성할 때는 장면의 광원 방향과 색온도를 맞추되, 캐릭터 자체의 소재가 금속·유리·네온으로 바뀌지 않게 한다.

## 검사 순서

1. 머리 실루엣과 얼굴 면
2. 2.7등신과 두 캐릭터 체형 균형
3. 기본복의 패널과 밑창
4. 화면 기준 오른쪽 가슴 상단의 작은 `T/P`
5. 머리·얼굴·팔다리·소품 무표식
6. 재질 분리, 중성광, 접지 그림자와 과도한 광택 여부

같은 동일성 오류가 두 번 반복되면 같은 프롬프트 재시도를 중단하고 승인 2D 앵커의 크롭, 3D 개별 시트, 패밀리 시트의 참조 조합을 바꾸거나 해당 부분만 국소 편집한다.

# 포항TP SNS 제작·게시 도구

## 설치

1. ZIP의 `ptp-sns-tool` 폴더를 각 직원의 Codex 사용자 스킬 폴더에 복사합니다. Windows에서 기존 스킬이 `%USERPROFILE%\.codex\skills`에 있다면 같은 위치의 `ptp-sns-tool\SKILL.md`가 되도록 둡니다.
2. 새 Codex 채팅에서 `$ptp-sns-tool`을 부릅니다. 기본 제작에는 Python과 Codex의 이미지 생성 도구를 사용합니다. 검수에는 Pillow, QR 생성·해독에는 스킬 안내의 QR 라이브러리를 사용합니다. 별도 글자 조판에서 Canvas 실측을 사용할 경우 Node.js와 `@napi-rs/canvas`가 필요합니다. MP4에는 FFmpeg·ffprobe, 한국어 음성 합성에는 Supertonic 3 로컬 환경을 사용합니다.
3. 공식 게시 담당자는 Meta Business Suite에서 직원 본인 계정으로 로그인합니다. 포항테크노파크의 인스타그램 `@pohangtp_official`과 페이스북 페이지 `pohangtpoffcial`에서 콘텐츠 작성 권한이 있어야 합니다.

## 첫 실행 예시

- `$ptp-sns-tool로 이 사업공고를 카드뉴스로 만들어줘. 테오·피오를 쓰고 검수 후 재단 인스타그램과 페이스북에 게시해줘.`
- `$ptp-sns-tool로 이 행사를 캐릭터 없이 소개하는 15초 영상으로 만들어줘. 파일만 전달해줘.`

최종 SNS 제작은 캐릭터와 함께 **검수 후 두 채널 게시**를 기본 선택으로 제시합니다. 게시 범위가 정해지면 검수 후 바로 진행합니다. **파일만**, **초안**, **인스타그램만**도 지정할 수 있습니다.

동일한 공식 계정을 여러 명이 운영하는 경우 재단의 동일한 발행 환경에서 기존 제작·게시 장부와 원본 패키지를 함께 사용합니다. 이 배포본은 기존 장부·개인 로그인 정보·자동화 일정을 포함하지 않습니다. 운영 중인 환경에 적용할 때 그 환경의 장부를 보존하고, 새 환경에서는 처음 게시하기 전 원격 게시·예약·초안을 대조합니다.

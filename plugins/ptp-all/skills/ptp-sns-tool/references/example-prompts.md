# 바로 쓰는 요청 예시

아래 예시는 초안 제작용이다. `【 】` 안을 실제 정보로 바꾸고, 확인되지 않은 수치·일정·연락처는 그대로 빈칸 표기로 남긴다.

## 카드뉴스

```text
$ptp-sns-tool를 사용해 포항테크노파크의 【사업명】을 소개하는 인스타그램 카드뉴스 【수량】장을 제작해줘. 대상은 【대상】이고, 핵심 내용은 【내용】, 신청 기간은 【기간】, 행동 유도 문구는 【CTA】야. 먼저 원문을 필수 결정 정보·보조 설명·원문 확인사항으로 나누고, 카드별 주 메시지와 가장 크게 보여줄 숫자 또는 행동을 정해줘. 각 카드의 보조 정보는 3묶음 이내로 제한하고, 원문 표를 그대로 옮기지 말아줘. 테오는 핵심 정보나 절차를 가리키고 피오는 다음 행동을 제안하게 해줘. 1080×1440px RGB PNG로 구성하고, 흑백 와이어프레임의 3초 독해를 확인한 뒤 검토용 시안을 만들어줘.
```

## 포스터

```text
$ptp-sns-tool를 사용해 【행사명】 A3 세로 포스터를 제작해줘. 일정·장소·문의처는 제공 자료만 사용하고, 파란 캐릭터는 핵심 정보를 가리키며 주황 캐릭터는 참여를 독려하게 해줘. 인쇄소 사양이 아직 없으므로 우선 검토용 RGB 시안을 만들고, 실제 인쇄 파일에 필요한 미확정 항목을 별도로 정리해줘.
```

## 안내판

```text
$ptp-sns-tool를 사용해 【시설/행사】용 가로 안내판을 설계해줘. 설치 크기는 【가로×세로 mm】, 예상 시청 거리는 【m】, 필수 안내 문구는 【문구】야. 캐릭터가 본문을 가리지 않게 배치하고 화살표·장소명·행동 지시를 가장 먼저 읽히게 해줘. 소재와 출력 방식은 【업체 사양】을 따르고, 없으면 제작 사양서까지만 작성해줘.
```

## 웹 배너

```text
$ptp-sns-tool를 사용해 【캠페인명】 웹 배너를 제작해줘. 데스크톱 【크기】와 모바일 【크기】 두 규격이며, 제목·기간·버튼 문구는 【확정 문안】을 사용해줘. 캐릭터와 텍스트를 별도 레이어로 설계하고, 좁은 화면에서는 주황 캐릭터를 우선 유지하는 재배치 규칙도 제안해줘.
```
# SNS·다중 출력·빠른 제작

## 사업공고 수집부터 두 SNS 게시까지

`$ptp-sns-tool로 포항TP 홈페이지 사업공고의 가장 최근 등록 글과 첨부자료를 확인해서, 테오·피오 카드뉴스와 인스타그램·페이스북 문안을 만들어줘.`

`$ptp-sns-tool로 최신 사업공고를 카드뉴스로 제작하고 설정된 재단 인스타그램과 페이스북에 게시해줘. 이미 게시한 공고면 중복 등록하지 말고 기존 링크를 알려줘.`

`$ptp-sns-tool의 이전 작업을 이어서, 성공한 인스타그램 게시물은 유지하고 미게시로 확인된 페이스북만 등록해줘.`

계정·로그인·게시 기능이 필요하면 준비된 콘텐츠를 보존하고 필요한 설정만 확인한다. 정기 실행은 별도의 명시적 요청이 있을 때 설정한다.

## 30초 빠른 초안

`$ptp-sns-tool를 사용해 【핵심 제목】을 알리는 Instagram 세로 피드 초안 1장을 빠르게 만들어줘. 테오와 피오를 함께 넣고, 검증과 멀티에이전트는 생략해. 우선 PNG만 만들어줘.`

## 카카오톡 채널 메시지

`$ptp-sns-tool를 사용해 【내용】을 안내하는 카카오톡 채널 관리자센터 와이드 이미지형을 만들어줘. 800×600 PNG와 내부 검토용 PDF를 함께 만들어줘.`

## Instagram·Facebook 동시 제작

`$ptp-sns-tool를 사용해 【지원사업】 카드뉴스 4장을 제작해줘. 먼저 Instagram·Facebook 유형별 크기를 안내하고, 통합 작성 방식으로 공통 원고를 Instagram 3:4 세로 피드와 Facebook 4:5 피드에 각각 재배치해줘. PNG 낱장, 묶음 PDF, HTML 미리보기를 만들어줘.`

## 여러 유형 개별 작성

`$ptp-sns-tool를 사용해 【캠페인】을 Instagram 피드, Instagram 스토리, 카카오톡 채널 와이드 이미지형으로 제작해줘. 먼저 유형별 크기를 안내하고 개별 작성 방식으로 각 채널의 문구·정보량·레이아웃을 따로 설계해줘.`

## 게시 준비 모드

`$ptp-sns-tool의 publication 모드로 【캠페인】 결과물을 준비해줘. 최신 공식 SNS 규격과 문구·권리·캐릭터 일관성을 검수하고, 게시 자체는 실행하지 말고 승인용 패키지만 만들어줘.`

## 실사 기반 상업 키비주얼

`$ptp-sns-tool를 사용해 【사업/행사】 카드뉴스를 상업 캠페인 수준으로 제작해줘. 입력 자료를 분석해 실사 현장형, 3D 공간형, 에디토리얼 콜라주형처럼 서로 다른 콘셉트 3안을 먼저 제안해줘. 선택안은 배경·분위기·환경·테오·피오·정보·Paperlogy 문자를 분리하고, 실사 합성이면 원근·광원·접지 그림자·가림·가장자리·색보정을 검수해줘.`

## 테오·피오 4컷 안내 웹툰

`$ptp-sns-tool로 【지원사업/정책】을 설명하는 Instagram용 4컷 안내 웹툰을 만들어줘. 테오가 대상과 원리를, 피오가 신청 행동을 설명하게 하고 훅→맥락→설명→CTA로 구성해줘. 컷마다 핵심 정보와 출처를 하나씩 연결하고, 원화·프레임·말풍선·Paperlogy 레터링을 분리해줘.`

## 세로 스크롤 교육 웹툰

`$ptp-sns-tool를 사용해 【주제】를 설명하는 세로 스크롤 교육 웹툰을 제작해줘. 입력에 맞는 서로 다른 시각 콘셉트 3안을 제안하고, 모바일 뷰포트별 정보 공개와 거터 리듬을 설계해줘. 테오와 피오는 승인된 기본복과 체형을 모든 컷에서 유지하고 다른 SNS 규격은 단순 리사이즈하지 말고 컷과 레터링을 재배치해줘.`

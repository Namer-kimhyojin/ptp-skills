# 데이터 기반 시각 콘셉트와 합성 체계

## 목적

입력 자료의 성격에 맞는 시각 언어를 고르고, 단순한 색상·도형 교체가 아닌 상업 캠페인 수준의 장면과 레이어를 설계한다. 저장된 콘셉트 원장은 `assets/visual-concept-presets.json`이다.

## 입력 신호 추출

다음 값을 먼저 구조화한다.

- 목적과 독자: 모집, 정책 안내, 행사 참여, 성과 홍보, 시설 안내, 기술 공개 등
- 핵심 정보: 혜택·지원금, 대상, 마감, 절차, 장소, 성과 수치, 제품·기술
- 정서와 인상: 신뢰, 전문성, 친근함, 역동성, 미래성, 따뜻함, 프리미엄
- 채널과 읽기 시간: 피드, 스토리, 메시지, 포스터, 안내판, 웹툰
- 사용 자산: 제공 사진, 생성 실사, 제품·시설 이미지, 로고, 권리 상태
- 현실성 선호: 실사, 시네마틱, 3D, 에디토리얼 콜라주, 촉감형, 아이소메트릭

## 콘셉트 3안 제안

매회 새 제작에는 [최근 제작물과 다른 서사·지면 선택](creative-variation.md)을 먼저 적용한다. `resolve_concept.py`는 공유 제작 이력과 이전 완성 패키지를 읽어 최근 콘셉트·매체군·서사·레이아웃 반복을 감점한다. 실제 미리보기도 확인하고 `creative_signature`를 남긴다. 아래 3안 비교만으로 시리즈 간 다양성이 검증됐다고 보지 않는다.

사용자가 콘셉트를 지정하지 않았으면 `scripts/resolve_concept.py`로 서로 다른 `medium_family`의 3안을 내부 비교한다. 세 안은 색상만 달라서는 안 되며 장면, 매체, 구도, 캐릭터 역할 중 둘 이상이 달라야 한다. 비교를 요청받으면 제시하고, 제작을 위임받았으면 적합한 한 안과 근거를 기록해 진행한다. 3안은 기획 계약이며 사용자 승인 질문 세 번을 뜻하지 않는다. SNS의 독자 질문·훅·캐릭터 행동은 [social-storytelling.md](social-storytelling.md)를 함께 적용한다.

각 안은 다음 기준으로 평가한다.

1. 입력 신호와 메시지 적합성
2. 독자의 첫 시선과 정보 이해도
3. 테오·피오를 기능적으로 참여시키는 방법
4. 채널별 재구성 가능성
5. 차별성·재질감·캠페인 확장성
6. 사진·브랜드·사실·권리 위험과 제작 가능성

`quick-draft`에서는 3안을 한 줄씩 제시하고 사용자가 `알아서`, `바로`를 요청하면 최고 점수 안을 자동 선택한다. `standard`와 `publication`에서는 선택안과 선택 근거를 작업 요청서에 남긴다. 사용자가 세 안의 저해상도 썸네일 비교를 요청하면 같은 정보·캐릭터 조건으로 비교 시안을 만들 수 있다.

## 다중 레이어 최소 구조

일반 이미지와 웹툰 원화 모두 다음 역할을 분리한다.

1. `background`: 제공·생성 실사, 일러스트 장면, 3D 공간 또는 혼합 매체
2. `atmosphere`: 빛, 공기 원근, 색조, 입자, 깊이
3. `context`: 장소·산업·제품·절차를 설명하는 환경 오브젝트
4. `character`: 승인 앵커를 사용한 테오·피오
5. `information`: 핵심 수치, 정보 패널, 아이콘, CTA 구조
6. `typography`: Paperlogy로 조판한 정확한 한국어
7. `brand-legal`: 필요한 로고, 출처, 문의처, 법적·AI 고지

도형은 정보 정렬과 대비를 돕는 보조 수단으로 사용할 수 있으나, 사용자가 `미니멀 도표형`을 명시하지 않은 이상 평면 도형만으로 배경과 콘셉트를 완성하지 않는다. 캐릭터·문자·프레임을 한 번에 이미지 모델에 굽지 않는다.

## 실사 기반 합성

실사 또는 사진 같은 장면을 쓰면 다음을 모두 검수한다.

- 제공 사진·제품·시설·인물의 사용 권리와 생성 도구 입력 허용 범위
- 카메라 높이, 소실점, 초점거리 느낌, 캐릭터 크기와 지면 접촉
- 주광 방향, 색온도, 노출, 대비, 반사광과 주변색 번짐
- 접지 그림자, 가림 관계, 반사, 표면 접촉과 깊이 순서
- 가장자리의 흰 테두리·후광 제거, 선명도·입자·노이즈·피사계 심도 통일
- 전체 색보정 후에도 테오·피오의 고유색과 얼굴 가독성이 유지되는지 확인

테오·피오는 사진 위에 붙인 스티커가 아니라 실제 장면의 조명과 공간을 공유하는 참여자로 보여야 한다. 합성 때문에 얼굴, 체형, 기본복 또는 가슴의 작은 `T/P`가 바뀌면 합격시키지 않는다.

## 상업 품질 기준

- 하나의 강한 캠페인 키비주얼과 명확한 시선 중심을 만든다.
- 일반 스톡 사진, 무작위 AI 미래도시, 네온·렌즈 플레어·글래스 카드 남용을 피한다.
- 재질, 빛, 공간, 사진·일러스트의 결합에 의도와 일관성이 있어야 한다.
- 첫 화면에서 `무엇`, `누구에게`, `왜 지금`, `다음 행동`의 우선순위가 보이게 한다.
- 시리즈는 같은 콘셉트 문법을 유지하되 카드마다 장면과 정보 기능을 바꾼다.
- 다른 비율은 단순 크롭·리사이즈하지 않고 주초점, 캐릭터, 레터링 안전영역을 재구성한다.

`상업적 완성도`는 권리·브랜드·사실·채널 정책 확인을 포함한다. 시각 품질이 높아도 이 항목이 열려 있으면 외부 게시 준비 완료로 표시하지 않는다.

## 개별·통합 작성

- `individual`: 지면별 목적이 다르면 서로 다른 콘셉트를 선택할 수 있다. 캐릭터 정체성과 캠페인 핵심 메시지는 유지한다.
- `integrated`: 하나의 선택 콘셉트와 공통 원고를 사용하되, 각 규격에 맞게 장면·레이어·문자 위치를 다시 조립한다.

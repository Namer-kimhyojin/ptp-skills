# 기관 CI·BI 원본 관리와 사용

새 홍보물에 실제 배치하는 공식 로고는 작업 폴더에만 두지 않는다. 게시 전 검수에서 파일·출처·사용조건을 확인하고, 미등록 원본은 `register_brand_asset.py`로 스킬의 `assets/brand-identities/`와 `registry.json`에 등록한다. 공식 배포 페이지 URL을 출처로 기록한다. 이미 등록된 동일 기관·변형·SHA-256 원본은 기존 파일을 참조한다. 이후 개정판을 추가해도 실제 사용한 기존 원본과 등록 기록은 삭제하거나 덮어쓰지 않는다.

job과 manifest에는 실제 배치한 로고별 기관명, 변형, 스킬 등록부 상대경로, SHA-256 및 출처를 남긴다. 텍스트로 표기한 기관에는 로고 사용 기록을 만들지 않는다. 이후 작업은 보관본을 먼저 조회하고 해당 공고의 기관 역할과 최신 사용조건을 다시 확인한다.

등록부의 `category`로 지자체·주무부처·전담기관을 찾고, `organization`과 `variant`로 파일을 선택한다. 분류는 검색 편의를 위한 것이며 해당 공고의 기관 역할은 원문에서 확인한다. 같은 기관에 여러 파일이 있으면 국내 홍보는 국문 가로 또는 국문 조합형을 우선한다. 심볼 단독·영문·세로형은 매체와 기관 가이드에 맞춰 고른다. 공식 웹 게시본은 해상도가 낮을 수 있으므로 크게 사용할 때는 공식 배포용 원본을 확보한다.

`assets/brand-identities/registry.json`에서 기관명·유형·이미지 파일·SHA-256·공식 출처·사용조건을 확인한다. 포항테크노파크 컬러·흰색 파일은 사용자가 2026-10-30 제공한 원본이며, 밝은 바탕은 컬러, 어두운 바탕은 흰색을 우선한다. 대비·안전여백과 가독성을 실제로 확인하고, 저대비면 다른 원본을 선택한다.

공고의 주최·주관·지원기관을 원문에서 확인한 경우에만 각 기관 로고를 사용하고, 목록에 있다는 이유만으로 관여·후원·보증을 암시하지 않는다. 기관 공식 자산 원본을 사용하고 형상·글자·색상·비율을 임의 재생성하거나 뒤섞지 않는다. 사용 전 SHA와 최신 공식 가이드 및 해당 용도의 사용조건을 확인한다. 출처표시·변경금지·비상업 등 등록된 제한을 존중하며 확인되지 않은 권리를 승인으로 취급하지 않는다. 특히 산업통상부 원본에는 공식 페이지의 공공누리 4유형이 표시되어 있다. 외부 저작물은 기관 CI 사용 조건과 상업적 이용 여부를 매 작업 확인한다.

사용자가 새 CI를 제공하거나 변경을 요청하면 원본 파일을 삭제·덮어쓰지 말고 다음 명령으로 새 버전을 등록한다. `--source`와 `--usage`는 실제 제공 근거·확인한 조건을 기록하며 모르는 조건은 미확인으로 쓴다. 기관명·변형·등록일·해시·출처·이전 버전과의 관계를 보존하고 이후 적절한 버전을 선택한다.

```powershell
python scripts/register_brand_asset.py --file <원본파일> --organization <기관명> --variant <컬러_또는_흰색_등> --source <출처> --usage <사용조건>
```

전체 이미지 생성의 원칙을 유지한다. 생성 모델이 공식 로고를 변형하면 원본과 비교해 실패로 기록하고 재생성한다. 사용자가 특정 작업의 로고 영역만 원본으로 교체하도록 명시하면 그 영역에 한해 정확한 원본을 비율 유지하여 반영하고, 나머지 픽셀·문자·QR 불변 및 QR 해독을 검사한다. 해당 권한을 다른 작업으로 확대하지 않는다. 결과물의 로고 사용 근거·버전·원본 해시·실제 검수를 job과 manifest에 남긴다.


제작 전에 공고 원문에서 표기할 전체 기관과 역할을 확정한다. 전 기관의 공식 원본과 사용조건이 확인된 경우 로고를 원래 비율로 배치한다. 포항테크노파크는 밝은 배경에 컬러, 어두운 배경에 흰색 원본을 우선한다.

한 곳이라도 공식 원본이 없거나 사용 가능 여부가 확인되지 않으면 해당 이미지의 기관 표기 전체를 정식 명칭 텍스트로 통일한다. 이때 포항테크노파크도 동일한 텍스트 규칙을 적용한다. 임의 생성·유사 심볼·일부 기관만 로고로 배치하는 방식은 사용하지 않는다. 명칭과 역할을 원문과 대조하고 텍스트 모드 선택 사유 및 미확인 기관을 검수에 남긴다.

자동 게시 job은 전체 공식 로고 사용 시에만 `ptp_ci_required=true`를 설정한다. 텍스트 모드에서는 `false`를 설정하고 각 이미지의 `reviews.brand`에 실제 명칭 대조와 로고 미사용 확인을 기록한다. 로고 모드에서는 각 이미지의 `reviews.brand`에 `status=passed`, 원본 대조 근거, 시각, 재단 CI의 `asset_file`과 `asset_sha256`을 기록하고 모든 사용 기관의 CI 근거를 manifest에 남긴다. 두 모드 모두 360px 가독성과 최종 PNG의 QR 및 해시를 재검수한다.

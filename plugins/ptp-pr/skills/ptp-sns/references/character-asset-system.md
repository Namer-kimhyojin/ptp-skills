# 테오·피오 정밀 에셋 운용 규격

## 기준 우선순위

1. 사용자 승인 `v1.0` 가이드는 이름·의미·머리 실루엣·기본복의 최상위 기준이다. 중앙 가슴 문자 위치는 폐기돼 더 이상 기준이 아니다.
2. `character-spec-v1.2.json`은 현재 가슴 문자 위치와 테오·피오 체형 통일 규칙의 최상위 기준이다.
3. 사용자 승인 `v1.2` 마스터 시트는 정면·3/4·측면·후면과 표정, 최신 가슴 문자 위치, 두 캐릭터 체형 균형을 유지하는 잠금 제작 앵커다.
4. 실루엣·기본복은 v1.0, 문자 위치·크기와 패밀리 체형은 v1.2를 따른다. 이 범위를 벗어난 충돌은 새로 만들지 말고 사용자에게 제시한다.

## 시트 구성

- 상단 네 칸: 정면 → 3/4 → 엄격한 측면 → 후면
- 하단 네 칸: 친근한 기본 → 밝은 미소 → 설명·자신감 → 걱정·배려
- 전신 네 시점은 같은 바닥선과 같은 시각 크기를 유지한다.
- 옆면과 후면에서는 보이지 않는 가슴 문자를 억지로 노출하지 않는다.
- 캐릭터 주위의 빈 배경은 생성 참조용이다. 결과물에 그대로 붙이는 완성 배경이 아니다.

## 형태 허용 오차

- 목표 비율: `2.7등신`, 허용 범위 `2.55~2.85등신`
- 한 시트 내 전신 시점 간 크기 차이: 최대 `3%`
- 바닥선 차이: 시트 높이의 최대 `1.5%`
- 머리 외곽, 얼굴 흰 면, 눈 간격, 손 크기, 신발 폭은 시점 전환 때문에 필요한 범위 외에는 바꾸지 않는다.
- 같은 프롬프트에서 복장, 머리 실루엣 또는 가슴 문자가 달라지면 새 변형으로 보지 않고 실패본으로 처리한다.

## 복장 잠금

### 테오

- 흰색 일체형 기본복
- 청색 옆선·어깨 배색·손목 테두리
- 흰색 하의와 청색 밑창
- 네이비 바지, 재킷, 치마, 큰 장갑 금지

### 피오

- 흰색 일체형 기본복
- 어깨에서 몸통·다리 바깥쪽으로 이어지는 주황 측면 패널
- 흰색 하의와 주황 밑창
- 네이비 바지, 주황 스웨트셔츠, 재킷, 벨트, 별도 장갑과 두꺼운 장갑 커프 금지

## 상징·문자 잠금

- 테오: 화면 기준 오른쪽 가슴 상단의 작은 청색 `T` 하나
- 피오: 화면 기준 오른쪽 가슴 상단의 작은 주황 `P` 하나
- 문자는 중앙 장식이 아니라 유니폼 자수처럼 절제된 크기로 사용한다. 정면 기준 기존 중앙 문자의 약 `35~45%` 높이를 기준으로 삼는다.
- 머리·얼굴·팔다리·소품에는 표식을 추가하지 않는다.
- `T/P`는 캐릭터 원화의 일부다. Paperlogy 또는 다른 글꼴로 다시 입력해 덮지 않는다.

## 두 캐릭터 체형 통일

- 테오와 피오는 약 `2.7등신`, 같은 어깨 폭 범위, 둥근 몸통 볼륨, 팔다리 굵기, 손과 신발 크기를 공유한다.
- 피오가 테오보다 가늘거나 길게 보이면 실패본으로 처리한다.
- 불꽃형 머리 실루엣만 피오 고유 차이로 남기고, 몸의 조형 언어는 테오와 같은 패밀리로 맞춘다.

## 마스터 시트 사용법

- 캐릭터 생성·편집 요청에 해당 캐릭터의 승인 가이드와 마스터 시트를 함께 넣는다.
- 승인 가이드는 `silhouette and default outfit authority`, 승인 마스터 시트는 `production anchor for view, expression, chest mark and body balance`라고 명시한다.
- 한 번에 인물·배경·긴 한국어 문구를 모두 생성하지 않는다. 캐릭터 장면과 한국어 레터링을 분리한다.
- 출력 후 `시점 → 실루엣 → 얼굴 → 복장 → 가슴 표식 → 머리 무표식` 순으로 검사한다.

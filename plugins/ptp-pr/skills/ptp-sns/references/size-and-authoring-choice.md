# 유형별 크기 안내와 작성 방식 선택

새 SNS 제작은 먼저 [단일 이미지/카드뉴스 선택과 10초 기본값](single-image-social.md)을 적용한다. 재단 단일 이미지 피드는 Instagram·Facebook 공용 1080×1080으로 제작하며 매번 아래 전체 규격·작성 방식·품질 질문을 추가로 요구하지 않는다. 명시된 요구나 다른 발행처가 있을 때 관련 규격을 안내한다. 실제 목록은 `assets/platform-presets.json`에서 읽고 아래 표는 사용자용 참고다.

표시 태그:

- `공식`: 공개 공식 문서에 픽셀 또는 비율이 명시됨
- `혼합`: 공식 비율 원칙과 제작용 픽셀 기본값을 결합함
- `제작 기본`: 빠른 제작을 위한 내부 권장값이며 플랫폼 보장값이 아님
- `참고`: 사용자 제공 자료의 값으로, 게시 준비 단계에서 재확인해야 함

## 첨부 참고표와 다른 현재 운영값

- 카카오톡 채널 `와이드 이미지형`은 현재 공식 관리자센터 가이드 기준 `800×600`이다. `800×400`은 기본 이미지·웰컴 이미지·와이드 리스트 첫 이미지 등에 사용한다.
- Facebook 페이지 커버는 첨부표의 `820×312` 대신 현재 공식 안내 프리셋 `851×315`를 우선한다.
- Instagram 세로 피드는 `1080×1440(3:4)` 현재형과 `1080×1350(4:5)` 호환형을 모두 제시한다.
- `참고` 유형은 바로 확정 규격으로 검증하지 않고, `publication`에서 공식 업로드 화면 또는 최신 공식 자료를 다시 확인한다.

## 웹툰·만화 형태 선택

웹툰 요청에는 채널 크기와 함께 다음 형태를 먼저 보여준다. 픽셀은 선택한 Instagram·Facebook·카카오톡 프리셋을 그대로 사용하고, 아래 값은 작품 조립 방식이다.

| 선택 유형 | 형태 | 시작 규격 | 작성 단위 |
|---|---|---|---|
| SNS 슬라이드 툰 | 3:4·4:5·1:1 | 선택한 피드 프리셋 | 슬라이드당 핵심 비트 1개 |
| 4컷 만화 | 정사각·가로·세로 스트립 | 채널 프리셋 우선 | 한 장 통합 또는 4장 분리 선택 |
| 교육·안내 만화 | 1~4컷 또는 다중 슬라이드 | 채널 프리셋 우선 | 주장·근거·행동을 컷별 분리 |
| 세로 스크롤 웹툰 | 가변 높이 | 작업 폭 1080px 제작 기본 | 모바일 뷰포트별 조립 후 채널 한도에 맞춰 분할 |
| 페이지 만화 | 단면·펼침면 | 인쇄소·발행처 사양 | 재단·도련·안전영역을 확인한 페이지 |

세로 스크롤의 `1080px`은 플랫폼 보장값이 아니라 재사용 가능한 원화를 위한 제작 기본값이다. 사용자가 발행처 규격을 주면 그 값을 우선하며, `publication`에서는 게시 시점의 공식 규격을 다시 확인한다.

웹툰도 `개별 작성`은 채널마다 컷 묶음·대사 밀도·프레임을 독립 설계하고, `통합 작성`은 같은 이야기 비트를 공유하되 채널마다 컷·거터·크롭·레터링을 다시 흐르게 한다.

## 최종 해상도 선택

유형과 작성 방식을 고른 뒤 [final-size-and-resolution.md](final-size-and-resolution.md)의 선택지를 함께 보여준다.

| 선택 | 의미 |
|---|---|
| 채널 표준 1× | 선택한 플랫폼 픽셀 그대로 게시용 제작 — 기본 권장 |
| 고해상도 마스터 2× | 2× 원본과 채널 표준 1× 업로드본을 함께 제작 |
| 사용자 지정 픽셀 | 지정한 가로×세로로 재구성 |
| 인쇄용 | 실제 크기(mm)와 DPI로 계산 |
| 빠른 미리보기 0.5× | 빠른 초안 확인 전용, 최종 납품 불가 |

종횡비가 달라지면 `재구성·크롭·레터박스` 중 하나를 선택하고 이미지 늘이기는 금지한다.

## 작성 방식 선택

규격 안내 직후 다음 두 선택지를 제시한다.

### 1. 개별 작성

- 선택한 각 플랫폼·유형마다 문구, 정보량, 카드 순서와 레이아웃을 독립적으로 설계한다.
- 여러 유형을 함께 선택해도 각 결과가 고유한 `content_variant_id`를 가진다.
- 채널별 최적화와 완성도를 우선할 때 사용한다.
- 제작 시간과 검토 항목은 통합 작성보다 늘어날 수 있다.

### 2. 통합 작성

- 하나의 핵심 문구·카드 순서를 공통 원본으로 잠근 뒤 모든 선택 규격에 맞게 재배치한다.
- 모든 대상이 같은 `content_variant_id=shared-main`을 사용한다.
- 단순 크기 조절은 금지하고 비율별 줄바꿈, 캐릭터 위치, 안전영역을 다시 조정한다.
- 같은 캠페인을 여러 SNS에 빠르게 배포할 때 사용한다.

사용자가 선택하지 않으면 대상이 하나일 때 `개별 작성`, 두 개 이상일 때 `통합 작성`을 제안하되 제작 전에 선택값을 한 번 보여준다.

## 사용자에게 보여줄 선택 예시

```text
원하는 유형을 골라주세요. 복수 선택할 수 있습니다.
- Instagram 피드 세로 현재형: 1080×1440, 3:4
- Instagram 스토리·릴스: 1080×1920, 9:16
- 카카오톡 채널 와이드 이미지형: 800×600, 4:3
- 세로 스크롤 웹툰: 작업 폭 1080px, 높이 가변·발행처 한도에 맞춰 분할

작성 방식도 선택해주세요.
1) 개별 작성: 유형별 문구·레이아웃을 각각 설계
2) 통합 작성: 공통 원고를 각 규격에 맞게 재배치

최종 이미지 품질도 선택해주세요.
1) 채널 표준 1×  2) 고해상도 2×+업로드본  3) 사용자 지정
4) 인쇄용(mm+DPI)  5) 빠른 미리보기 0.5×
```

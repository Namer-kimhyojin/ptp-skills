# 보도자료 통합 작성 원칙

이 문서는 사용자가 제공한 일반 기사쓰기 안내 PDF와 포항TP 내부 보도자료 교육자료 PPTX의 핵심을 요약한 작업 기준이다. 두 자료가 다르면 포항TP 내부 교육자료, 등록 HWPX 양식, 사용자의 현재 지시 순으로 우선한다. 원문 자료를 복제하지 말고 작성 원칙만 적용한다.

## 1. 독자와 뉴스 판단

- 내부 보고가 아니라 일반 독자를 위한 기사 재료로 쓴다.
- 기관이 알리고 싶은 내용보다 독자가 먼저 알아야 할 사실을 앞세운다.
- 계획서에 있는 기간, 예산, 현황, 추진 절차, 문제, 조치, 기대 효과를 사실 카드로 정리한다.
- 다른 기관·언론의 유사 기사는 구조 참고에만 쓰고 문장이나 표현을 베끼지 않는다.

## 2. 제목과 리드

- 제목은 10단어 이내를 우선하되, 제목과 부제목을 한 조합으로 읽었을 때 핵심 보도내용이 분명하게 한다.
- 의미가 자연스럽게 드러나면 제목에 담고, 억지로 결합하면 상투적인 문형이 되므로 부제목이나 본문에서 설명한다.
- 모호하거나 선정적인 표현, 전문용어, 중복 의미, 과도한 기호를 피한다.
- `최초`, `최고`, `1위`는 객관적 근거가 확인된 경우에만 쓴다.
- 부제목은 1~2줄로 작성해 일시·장소·규모·대상·핵심 프로그램·성과 중 강한 세부 사실을 요약한다.
- 부제목은 각 줄 앞에만 `- `를 붙이고 끝에는 닫는 `-`를 붙이지 않는다.
- 제목의 표현을 부제목에서 반복하지 말고 새로운 근거를 더한다.
- 본문을 정리한 뒤 [제목·부제목 설계 프레임워크](headline-subtitle-framework.md)에 따라 서로 다른 관점군 5개 이상에서 내부 후보 7개 이상을 만든다.
- 후보는 사실 정확성·뉴스 명확성·구체성·독자 관련성·차별성·간결성·제목과 부제목의 보완성을 비교한다. 기관명이나 특정 서술어를 모든 후보에 반복하지 않고 의미상 중복 후보를 제거한다.
- 새 보도자료는 차이가 분명한 제목·부제목 조합 3~5개를 사용자에게 먼저 제안한다. 사용자가 선택하거나 선택을 위임한 뒤에 본문을 작성한다.
- 첫 문단은 누가, 언제, 어디서, 무엇을 했는지 중심으로 짧게 쓴다.
- 첫 리드에서 새로운 행위 주체를 제시할 때는 `이/가`를 사용한다. 포항TP 기본 문형은 `포항테크노파크(원장 [성명], 이하 포항TP)가`이다.
- 괄호 안 설명이 있어도 조사는 괄호 앞 중심 명사의 받침 여부에 맞춘다. 이후 문단에서 이미 제시한 기관을 화제로 이어갈 때는 `은/는`을 사용할 수 있다.
- 목적과 배경을 첫 문단에 과도하게 넣지 말고 두 번째 문단으로 넘긴다.

## 3. 본문 구성

중요한 사실부터 배치하는 역피라미드 구조를 사용한다. 일반 보도자료는 `❍` 문단 6개 이상을 기본으로 하며, 통상 6~8개로 구성한다.

1. 리드: 누가·언제·어디서·무엇을 했는지
2. 목적·역할: 행사·사업의 취지와 추진 배경, 주최·주관·후원
3. 세부 1: 일정·장소·대상·규모·절차
4. 세부 2: 프로그램·지원 내용·확인된 수치와 방법
5. 효과·이용 정보: 대상에게 주는 효과, 신청·문의·후속 계획
6. 인용: 원장 인용과 기관의 추진 방향
7. 선택 문단: 관련 사업이나 별도 후속 일정이 있을 때만 추가

- 편집 과정에서 뒷부분이 줄어도 핵심 뉴스가 남도록 쓴다.
- 한 문단에는 한 가지 핵심 사실만 둔다.
- 문단 수를 맞추기 위해 같은 사실을 표현만 바꿔 반복하지 않는다.
- 정보가 부족한 초안은 필요한 위치에 공란이나 `[확인 필요]`를 남기고, 최종본에서는 6개 이상의 문단이 각각 새로운 정보를 담도록 보완한다.

### 행사·사업의 기관 역할

- 행사·사업은 두 번째 문단에 주최·주관·후원 기관을 공식 명칭으로 밝힌다.
- 공동주최·공동주관·협력·운영대행은 서로 다른 역할이므로 섞어 쓰지 않는다.
- 협력관계나 전년도 자료만으로 현재 역할을 추정하지 않는다.
- 후원기관이 없으면 `후원 없음`을 확인한 뒤 후원 문구를 생략한다.
- 초안은 확인되지 않은 역할을 자리표시자로 남길 수 있지만 최종본은 모두 해소한다.

## 4. 문장과 표기

- 쉬운 말과 대화하듯 자연스러운 문장을 사용한다.
- 한 문장에 여러 사실을 `~며`, `~고`로 길게 잇지 말고 의미 단위로 나눈다.
- 문장마다 주체를 분명히 하고 주어와 서술어의 호응을 확인한다.
- 소리 내어 읽어 어색한 관공서 문체, 중복어, 전문용어를 줄인다.
- `오늘`, `내일`, `어제`, `지난`, `오는` 대신 실제 날짜를 쓴다.
- 금액 범위는 `300~400만 원`처럼 양 끝의 자릿값과 단위를 분명히 쓴다.
- 법인 표시 `(재)`, `(주)`는 뉴스 문장에 불필요하면 생략한다.

## 5. 원장 인용문

- 사용자가 실제 발언을 주지 않아도 확인된 본문 사실에서 내부 검토용 초안을 작성한다.
- 행사·사업의 취지·목적·대상 효과를 먼저 말하고, 포항TP의 추진 방향·지원 의지·지역 산업의 의미로 마무리한다.
- 1~2문장으로 자연스럽게 쓰며 확인된 원장명과 발언 귀속 표현을 넣는다.
- 본문에 없는 수치, 성과, 약속, 신규 사업이나 확정되지 않은 계획을 만들지 않는다.

## 6. 배포와 사진

- 행사가 끝난 결과 보도자료는 가급적 당일, 늦어도 다음 날 배포할 수 있게 준비한다.
- 내부 검토용 초안은 배포 1~2일 전 제출을 기준으로 한다.
- 금요일 배포는 가급적 피하고, 보도 시점이 필요한 경우 주최·주관기관과 엠바고를 미리 조율한다.
- 화면용 완성본을 제공한 뒤에는 배포양식 HWPX 파일도 작성할지 사용자에게 확인한다. 사용자가 처음부터 파일까지 요청했으면 다시 묻지 않고 확정된 내용으로 생성한다.
- 사진은 문서에 삽입하지 않고 원본 파일 1~3매를 별도로 제공한다.
- 대표성이 분명하고 인물의 뒷모습 위주가 아닌 사진을 고른다.
- 사진 파일명에는 행사명·일자·장면 설명이 드러나게 한다.
- 참고자료도 본문과 구분해 별도 파일로 제공한다.

## 7. 최종 검수

- 제목·부제목·첫 문단만 읽어도 뉴스가 무엇인지 알 수 있는가
- 제목 후보가 서로 다른 방식과 문장 구조로 작성됐는가
- 날짜·요일·시제·장소·기관명·사업명이 공식 자료와 일치하는가
- 예산·인원·기간·성과 수치에 근거가 있는가
- 주최·주관·후원·수행기관 역할이 구분됐는가
- 원장명과 담당자 연락처가 현재 정보인가
- 인용문이 목적과 추진 방향을 담되 새로운 사실을 만들지 않았는가
- 자리표시자, 내부 검토 메모, 오래된 연락처가 남아 있지 않은가
- 사진과 붙임자료 개수가 실제 제공 파일과 일치하는가

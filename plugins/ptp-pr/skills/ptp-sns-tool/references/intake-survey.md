# 제작요청 설문과 납품 후 피드백

## 요청 직후 묶음 설문

사용자가 이미 답한 항목은 다시 묻지 않는다. 질문 전에 [size-and-authoring-choice.md](size-and-authoring-choice.md)에서 요청 플랫폼에 해당하는 유형·형태·크기를 간단히 보여준다. 플랫폼이 정해지지 않았으면 각 플랫폼의 대표 피드·세로·메시지 규격만 먼저 보여준다. 첫 응답은 최대 3개의 짧은 묶음 질문으로 끝낸다.

1. `목적·핵심`: 무엇을 알리며 가장 먼저 보여줄 한 문장·수치·마감일은 무엇인가? 카드뉴스·포스터·안내판·웹툰 중 원하는 형식이 있는가?
2. `유형·작성 방식·산출`: 안내된 크기 중 어떤 유형을 선택하며 `개별 작성`과 `통합 작성` 중 어느 방식인가? 최종 해상도는 표준 1×·고해상도 2×·사용자 지정·인쇄용·빠른 미리보기 중 무엇인가? PNG·PDF·HTML 중 무엇이 필요한가? 복수 유형 선택이 가능하다.
3. `콘셉트·제작 수준`: 관련 실사 사진·제품·시설 이미지와 사용 권리가 있는가? 입력 내용 기반 콘셉트 3안 자동 제안을 받을 것인가? `빠른 초안`, `정식 제작`, `게시 준비` 중 무엇인가?

사용자가 규격을 모르면 목적에 맞는 기본 프리셋을 먼저 제안한다. 결과를 크게 바꾸지 않는 미입력값은 합리적인 기본값으로 채우고 가정 목록에 남긴다.

## 30초 빠른 설문

`quick-draft`에서는 다음 세 값만 있으면 시작한다.

- 채널 유형 또는 대표 비율, `개별 작성|통합 작성`, 최종 해상도 프로필
- 핵심 제목 한 줄
- 필요한 파일 형식과 장수

CTA가 없으면 초안 기본값 `자세히 보기`, 출처가 없으면 `확인 필요`를 자동 입력해 추가 질문 없이 시작한다. 미확정 날짜·금액·연락처는 창작하지 않고 `확인 필요`로 둔다. 대표 규격 한 개를 먼저 만들고, 사용자가 방향을 고르면 나머지 규격을 확장한다.

빠른 초안에서 해상도를 고르지 않으면 `draft-preview-0.5x`를 사용한다. 방향 승인 뒤에는 미리보기 파일을 확대하지 않고 분리 원본에서 `channel-native-1x` 또는 사용자가 선택한 최종 프로필로 다시 렌더링한다.

## 기본값

- 제작 모드: `standard`
- 작성 방식: 유형 1개는 `individual`, 유형 2개 이상은 `integrated`를 먼저 제안
- 빠른 요청의 대표 출력: `PNG`
- 최종 해상도: 정식 디지털 결과물은 `channel-native-1x`, 빠른 초안은 `draft-preview-0.5x`
- 카드뉴스 장수: 사용자가 지정하지 않으면 정보량을 보고 제안
- 캐릭터: 기술·정책 설명은 테오, 행동·성장 제안은 피오, 종합 안내는 둘 다
- 서체: Paperlogy
- 외부 게시·업로드·발송: `false`
- 시각 콘셉트: 입력 신호에 맞는 서로 다른 매체군 3안 제안 후 선택
- 합성 방식: 다중 레이어, 평면 도형만으로 완성 금지
- 웹툰: 1~4컷은 축약 경로, 5컷 이상은 연속성 경로

## 납품 후 설문

최종 결과물을 전달한 뒤 수정이 필요한 경우에만 다음 세 항목을 한 번에 묻는다.

1. 정보와 문구가 정확하고 읽기 쉬운가?
2. 디자인·색상·SNS 화면 적합성이 만족스러운가?
3. 테오·피오의 얼굴·체형·복장·가슴 `T/P`가 일관적인가?

선택 답변은 `만족`, `부분 수정`, `전면 수정`으로 받고 자유 의견을 함께 받을 수 있다. `부분 수정`이면 바꿀 항목만 수정하고, 승인된 요소는 다시 생성하지 않는다.

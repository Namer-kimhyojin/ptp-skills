# 정보전달형 시각 디자인

이 문서는 카드뉴스·포스터·안내판·배너에서 정보는 정확하지만 읽히지 않거나 심미성이 떨어지는 결과를 막기 위한 제작 기준이다.

시각 콘셉트 선택, 다중 레이어와 실사 합성은 [visual-concept-system.md](visual-concept-system.md)를 함께 적용한다. 아래의 그리드·색·정보 패널은 장면을 정리하는 구조이지 독립적인 시각 콘셉트가 아니다. 사용자가 미니멀 도표형을 명시하지 않은 이상 평면 도형만으로 결과를 완성하지 않는다.

## 기본 서체 — Paperlogy

- 내장 위치: `assets/fonts/paperlogy`
- 웹·HTML 조판: `assets/fonts/paperlogy/paperlogy.css`를 불러오고 `font-family: var(--ptp-font-family)`를 적용한다.
- 제목·핵심 숫자: `700~900`
- 소제목·라벨·버튼: `600`
- 본문·주석: `400~500`
- 한 카드의 위계는 크기와 굵기로 만들되 본문에 3개 이상의 굵기를 섞지 않는다.
- 가슴의 `T/P`는 캐릭터 원화이므로 Paperlogy 문자로 재입력하지 않는다.

## 1. 먼저 읽힐 것 하나

한 화면에서 가장 먼저 읽힐 `hero_metric`을 하나만 정한다. 보통 다음 중 하나다.

- 혜택: 기업당 최대 지원금, 할인율, 제공 규모
- 시간: 마감일, 행사일, 운영시간
- 대상: 신청 가능한 핵심 조건
- 행동: 신청, 방문, 등록, 문의

제목과 `hero_metric`이 경쟁하지 않게 한다. 제목은 맥락을 설명하고, `hero_metric`은 판단을 돕는다.

## 2. 카드별 문구 예산

1080×1440 카드의 시작 기준은 다음과 같다. 정보 성격에 따라 조정할 수 있지만, 초과하면 글자를 줄이지 말고 분리한다.

- 주 메시지: 1개
- 보조 정보 묶음: 최대 3개
- 행동 유도: 1개
- 본문: 공백 포함 약 180자 이내
- 출처·원문 우선 문구: 별도 하단 영역

기관 문서를 그대로 옮긴 표, 긴 자격요건, 예외 목록은 카드 본문이 아니라 원문 확인 대상으로 보낸다.

## 3. 정보 유형별 구성

### 금액·혜택형

`큰 지원금/혜택 → 2~3개 선택지 → 조합 또는 부담 조건 → 원문 안내` 순서로 구성한다. 지원금과 총예산을 같은 크기로 만들지 않는다.

### 마감·신청형

`마감일·시간 → 3단계 이내 접수 흐름 → 필수 파일/채널 → 행동 유도` 순서로 구성한다. 금액 예시는 보조 패널 하나로 제한한다.

### 대상·자격형

`핵심 지역/대상 → 충족 방법 2~3개 → 주요 제외사항 1개 → 상세 조건 원문 안내` 순서로 구성한다.

### 장소·안내형

`장소/방향 → 이동 행동 → 운영시간/문의` 순서로 구성하고 화살표와 QR을 캐릭터보다 우선한다.

## 4. 기본 시각 체계

1080×1440 디지털 카드의 시작값이며, 채널과 문구에 맞게 조정한다.

- 안전 여백: 좌우 64px 이상
- 제목: 52~72px
- 핵심 숫자: 64~96px
- 보조 제목: SNS에서는 36~48px부터 검토
- 본문·대사: SNS에서는 39~48px부터 검토하고 약 360px 폭에서 실제 독해 확인. 짧은 보조 출처는 더 작게 둘 수 있지만 대상·마감·제한 조건을 작은 주석으로만 처리하지 않는다.
- 요소 간격: 8px 배수 사용
- 빈 공간: 화면의 약 25~35%를 목표로 하되 캐릭터 배경 여백도 포함해 판단
- 색 비중: 중립 배경을 가장 넓게, 파랑을 구조·신뢰, 주황을 숫자·행동 강조에 사용

모든 숫자·박스에 강조색을 쓰지 않는다. 가장 중요한 항목 하나에만 강한 대비나 그림자를 집중한다.

## 5. 캐릭터 통합

- 테오는 기술·정책·절차를 가리키거나 설명한다.
- 피오는 신청·참여·성장 행동을 유도한다.
- 두 캐릭터를 쓰면 서로 같은 방향을 가리키지 말고, 테오는 정보, 피오는 다음 행동을 맡긴다.
- 캐릭터는 정보 패널과 시각적으로 연결되어야 한다. 별도 하단 띠에 장식처럼 놓지 않는다.
- 얼굴과 가슴 `T/P`가 보이되 핵심 숫자나 CTA보다 먼저 시선을 빼앗지 않게 크기와 대비를 조절한다.

## 6. 피해야 할 구성

- 원문 표나 PDF 페이지를 카드 안에 축소 재현
- 모든 사실을 같은 크기의 흰 박스에 반복 배치
- 한 카드에 핵심 숫자·대상·절차·연락처를 모두 동급으로 강조
- 작은 글자로 정보를 억지로 채우기
- 캐릭터를 본문과 무관한 하단 장식으로 사용
- 캐릭터 배경의 빈 여백을 그대로 남겨 화면이 이중으로 나뉘게 하기
- 강조색, 둥근 모서리, 그림자를 모든 요소에 동일하게 적용

## 7. 2단계 시각 검수

조판 전에 [문자·말풍선 실측 검사](lettering-safety.md)를 적용한다. 가로 폭뿐 아니라 이름표·모든 줄의 실제 높이·아래 여백을 부모 영역별로 검사한다. 아래 시각 검수는 이 검사를 대신하지 않는다.

### 50% 축소 보기

3초 안에 다음을 말할 수 있어야 한다.

1. 이 카드가 무엇을 안내하는가
2. 가장 중요한 숫자·날짜·행동은 무엇인가
3. 다음에 무엇을 해야 하는가

### 실제 크기 보기

- 본문 줄바꿈이 자연스럽고 단위가 분리되지 않는다.
- 캐릭터 손·시선이 정보와 연결된다.
- 텍스트와 캐릭터가 안전영역·하단 출처를 침범하지 않는다.
- 한 편의 색상·서체·출처 식별은 일관되며 장별 기능에 맞게 컷·제목·말풍선·정보 위치를 변주한다. [최근 제작물 비교](creative-variation.md)를 적용한다.

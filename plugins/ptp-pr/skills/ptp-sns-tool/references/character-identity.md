# 캐릭터 정체성 계약

## 공통 불변값

- 약 2.7등신의 프리미엄 큐트 비인간 마스코트
- 같은 손·신발·몸통 비율과 또렷한 벡터형 윤곽
- 밝은 중성광과 부드러운 2단 명암
- 작은 화면에서도 색상과 머리 실루엣으로 즉시 구분
- 화면 기준 오른쪽 가슴 상단의 작은 `T/P` 외에는 문자·로고·워터마크를 캐릭터 원화에 생성하지 않음

## CHR-BLUE — 테오 TEO

- 이름 의미: `Technology + Opportunity`. 기술과 기업의 기회를 연결하는 안내자
- 기본 역할: 기술, 정책, 절차와 데이터를 빠르고 친절하게 설명
- 핵심 실루엣: 단정한 비대칭 보브를 연상시키는 일체형 청색 머리
- 얼굴: 젊고 힘찬 여성형 인상을 눈매와 얼굴선으로만 절제해 표현
- 상징: 화면 기준 오른쪽 가슴 상단의 작은 영문 `T` 하나만 사용
- 대표 동작: 한 발 전진, 안내하는 열린 손, 작은 힘찬 주먹
- 금지: 머리·얼굴·팔다리의 표식 또는 상징물, 안테나, 리본, 치마, 과장된 속눈썹, 흰 장갑, 큰 손목 장치

## CHR-ORANGE — 피오 PIO

- 이름 의미: `Pohang + Innovation + Opportunity`. 포항의 혁신과 기회를 기업 성장으로 피워 올리는 동반자
- 기본 역할: 실행, 도전, 기업 성장과 다음 행동을 제안
- 핵심 실루엣: 몇 개의 큰 곡선으로 만든 위로 흐르는 주황 불꽃 형태
- 얼굴: 파란 캐릭터와 같은 단순화 수준의 자신감 있는 표정
- 상징: 화면 기준 오른쪽 가슴 상단의 작은 영문 `P` 하나만 사용
- 대표 동작: 몸을 앞으로 기울인 실행 자세, 열린 손·엄지·주먹 동작
- 기본복: 흰색 일체형 기본복, 주황 어깨·측면 패널, 흰색 하의와 주황 밑창
- 금지: 머리·얼굴·팔다리의 표식 또는 상징물, 뾰족한 불꽃 왕관, 복잡한 불꽃 조각, 네이비 바지, 주황 스웨트셔츠, 재킷, 별도 장갑, 과대 신발, 큰 손목 장치

## 상징물 배치 잠금

- 테오의 상징물은 화면 기준 오른쪽 가슴 상단의 작은 영문 `T`, 피오의 상징물은 같은 위치의 작은 영문 `P` 하나뿐이다.
- 중앙 대형 `T/P`는 사용하지 않는다. 문자는 유니폼 자수처럼 작고 절제된 크기로 유지한다.
- 두 캐릭터가 함께 있으면 `T + P = TP`가 되어 Technopark 정체성을 완성한다.
- 머리 실루엣은 색과 형태만으로 식별하며 데이터·연결·성장·계단·불꽃 아이콘을 추가하지 않는다.
- 의상과 소품에도 유사 로고를 반복하지 않는다. 안전모·태블릿·클립보드의 표면은 무표식이 기본이다.
- `T`와 `P`의 서체·두께·크기는 가이드 이미지 기준으로 잠그고, 공식 CI 검토 후 최종 승인한다.
- Paperlogy는 안내 문구용이며 가슴 `T/P`에 적용하지 않는다.

## 패밀리 체형 잠금

- 테오와 피오는 약 2.7등신, 같은 어깨 폭 범위, 둥근 몸통 볼륨, 팔다리 굵기와 손·신발 크기를 공유한다.
- 피오를 테오보다 슬림하거나 길게 그리지 않는다.
- 두 캐릭터의 구분은 체형 격차가 아니라 머리 실루엣과 파랑·주황 색으로 만든다.

## 임시 색상 토큰

- `PTP-BLUE-SAMPLED`: `#064191`
- `PTP-ORANGE-SAMPLED`: `#EF7D00`
- `PTP-NAVY-SUPPORT`: `#102A43`
- `PTP-WARM-WHITE`: `#FAF8F3`
- `PTP-PALE-GRAY`: `#E9EEF3`

파랑과 주황 값은 사용자 제공 CI 이미지에서 측정한 임시 토큰이다. 공식 CI 가이드 확인 전에는 공식 팔레트로 단정하지 않는다.

## 의상 슬롯

- `default`: 기본 실루엣과 상징이 모두 보이는 일체형 기본형
- `field`: 안전모·태블릿·클립보드 중 핵심 소품 하나만 추가
- `research`: 연구복 오버레이·데이터 태블릿·샘플 케이스 중 하나만 추가

의상은 기본 머리 실루엣과 등신 비율을 바꾸지 않는다. 새로운 슬롯은 기준 이미지를 승인한 뒤 추가한다.

## 최소 앵커

두 캐릭터 각각 정면·측면·후면, 핵심 표정 4종, 모든 의상 슬롯 기준 이미지를 가져야 한다. 실제 결과마다 얼굴·의상·해부 검사를 분리해 기록한다. 같은 동일성 오류가 두 번 반복되면 같은 프롬프트 재시도를 중단하고 앵커·구도·국소 편집 전략을 바꾼다.

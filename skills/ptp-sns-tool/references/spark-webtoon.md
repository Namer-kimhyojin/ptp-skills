# PTP 반짝 웹툰

“반짝 웹툰”, “오래된 유머를 웹툰으로”, “병맛 단편”처럼 재미를 우선하는 요청에 적용한다. 사업공고 요약·기관 설명 연재와 별도 제작 유형이며 기존 테오·피오 연재의 편성·출연진·게시 권한을 바꾸지 않는다.

산업 이슈와 기초지식을 설명하는 일일 연재는 [산업 한 컷](spark-industry-daily.md)의 출처·편성·교육 검수를 적용한다.

## 호출과 기본값

- `workflow=creative`, `content_category=spark-webtoon`, `content_mode=social-toon`으로 기록한다. 예: “PTP 반짝 웹툰으로 옛 유머를 각색해줘”, “병맛 창작 단편을 5장으로 만들어줘”.
- 제작·게시 장부에는 단편 `ptp:spark:<작품-slug>:oneshot`, 연속 회차 `ptp:spark:<작품-slug>:ep01`처럼 안정된 키를 사용한다. 같은 작품의 캡션·이미지 개정마다 새 키를 만들지 않는다. 실제 모집 홍보가 아닌 순수 허구 단편은 공고 접수기간 검사 대상이 아니며 권한·파일 검수·계정 점유·중복 게시 검사는 유지한다.
- 작은 시리즈명은 **PTP 반짝 웹툰**, 큰 작품명은 반전의 정답을 숨기는 제목이다. 기본은 **1:1 정사각형 약 5장**, 장 번호대로 세로 읽기와 SNS 캐러셀을 지원한다. 사용자가 지정한 장수·비율·주제를 우선한다.
- 테오·피오는 기본 출연시키지 않는다. 사람이 없는 사물극, 오리지널 인물, 사용자가 고른 저장 세트 중 소재에 맞게 구성한다. 사용자가 캐릭터 자체를 제외하면 사물·상황·내레이션으로 만든다.
- 오리지널 인물을 쓰면 외형·복장·좌우 위치·소품의 앵커와 권리 근거를 보존한다. 저장 세트 기반 job은 [캐릭터 등록](character-sets.md) 절차로 실제 세트를 등록해 적용한다. `character-set none`은 인물이 전혀 없는 제작용이며 오리지널 등장인물을 숨겨 캐릭터 검사를 생략하는 우회로 쓰지 않는다. 제작 요청만 받았으면 새 마스터 시트 등록을 위해 작업을 불필요하게 확대하지 말고 실제 출연진을 콘티와 납품 manifest에 명확히 남긴다.

## 소재와 개그

- **오래된 유머 각색**: 확인 가능한 출처와 확인일, 가져온 발상, 새로 만든 장면·대사를 구분한다. 구전 유머의 기억을 정본·저작권 소멸·실제 인물의 발언으로 단정하지 않는다. 원문을 길게 전재하지 않고 새 상황과 시각 연출로 각색한다.
- **병맛 창작**: 일상적 질문·사물·직장 상황에서 한 가지 이상한 규칙을 정하고 그 규칙을 진지하게 밀어붙인다. 앞 장의 원인으로 오해가 커지고 마지막 행동·소품 공개로 전환되게 한다. 유행어 나열·갑작스러운 바보 행동·과장된 얼굴만으로 웃음을 대신하지 않는다.
- 5장 예시는 `일상과 질문 → 그럴듯한 오해 → 오해 확대 → 짧은 균열·정적 → 시각적 반전과 추가 한 방`이다. 소재의 리듬에 따라 변형하고 매번 같은 컷·카메라·말풍선 틀을 복제하지 않는다. 인물의 진지한 태도와 그림의 엉뚱함, 침묵·생략도 활용한다.
- 기관 이름은 배경·공간·관계로 자연스럽게 드러낼 수 있다. 순수 재미물에 정책 설명·지원조건·QR·신청 CTA를 강제하지 않는다. 실제 지원 보장이나 재단의 실제 상담 사례로 오인할 장면은 허구임을 구분한다. 특정 세대가 웃거나 확산될 것을 보장하지 않는다.

## 반전과 출처 배치

작품명·첫 장의 소제목·도입 문구·첫 장 대체텍스트에서 원전명이나 반전의 정답을 미리 알려주지 않는다. 현재 사례에서는 `최불암 시리즈 각색`을 표지에 넣지 않고, 작은 `PTP 반짝 웹툰`과 `수상한 대표님`을 사용한다. 다른 작품에 이 제목을 반복 적용하지 않는다.

출처·각색 안내는 결말 이후 별도 영역과 제작 기록에 둔다. 대체텍스트는 각 장의 실제 내용을 충실히 설명하되 뒤 장의 결말을 앞당겨 쓰지 않는다. 추모 문구는 사용자가 요청한 작품에만, 확인한 사실과 요청 문구를 바탕으로 본편 제일 하단에 별도 배치한다. 이번 작품의 추모를 모든 옛 유머 작품의 기본값으로 만들지 않는다.

사용자가 추모 초상을 요청하면 실제 인물의 확인 가능한 외형 자료를 바탕으로 흑백 캐리커처 등 지정 형식으로 새로 그릴 수 있다. 웹툰의 가상 등장인물과 구분되는 별도 추모 영역에 두고, 사진·언론사 그래픽을 그대로 붙이거나 원래 그래픽의 문구·로고를 복제하지 않는다. 사용한 얼굴 참조의 출처와 생성된 초상을 구분해 제작 기록에 남긴다.

## 제작·검수·납품

[웹툰 모드](webtoon-content-mode.md)의 연속성과 **[대사 읽기 순서](dialogue-reading-order.md)**를 적용한다. 그림·말풍선·확정 한글을 함께 만드는 `generation_method=whole-image`, `lettering_mode=native-integrated`가 기본이다. 반복 인물은 실제 앵커와 앞 장을 참조한다.

[컷별 장면 변화](creative-variation.md#웹툰의-컷별-장면-변화)를 적용하고 그림 재활용은 가급적 피한다. 같은 그림의 말풍선 교체로 대화를 늘리지 않는다. 장별로 새 행동·카메라·표정·소품 공개를 그려 오해와 긴장을 진전시키고, 완성 장을 나란히 비교해 실제 변화를 확인한다.

매 장에 중심 사건과 `page_peak`를 두고 극적 연출을 확인한다. 인접 컷에서 같은 구도·표정·물건을 든 자세를 반복하지 않는다. 동일한 찡그린 얼굴을 확대하는 것만으로 장면이 고조됐다고 보지 않는다. 기대·과열·침묵·반전 등 장의 역할에 따라 몸짓과 감정·화면의 밀도를 바꾸고, 마지막 마무리 컷도 앞 컷과 다른 연기로 그린다.

최종 파일의 실제 정사각형 비율, 장 순서, 발화·화자·꼬리·여백·오탈자·넘침, 반전 공개 시점과 원본/360px 가독성을 확인하고 해시와 연결한다. 모델 검수와 실제 독자 반응을 구분한다. 공개용 제작이면 기존 권리·브랜드·AI 표시·계정·중복 게시 검사를 적용한다.

요청 형식에 맞춰 장별 PNG, 순서가 검증된 ZIP과 세로 읽기 미리보기를 제공한다. 재단 공식 SNS 최종 제작은 [게시 기본값](default-publication.md)에 따라 게시 범위를 확정하고 검수 후 제출한다.

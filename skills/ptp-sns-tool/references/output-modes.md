# 출력 모드

## 공통 입력

모든 모드는 목적, 독자, 게시·설치 채널, 정확한 문구, 캐릭터 역할, 크기, 수량, 파일 형식, 납품 단위와 검수자를 기록한다. 규격 출처와 확인일 없이 플랫폼 호환이나 인쇄 적합을 보장하지 않는다.

## `card-news`

- 기본 용도: 인스타그램 슬라이드형 정책·사업 안내
- 프로젝트 기본값: 1080×1440px, RGB PNG. 수량은 사용자 지정이 우선이며 미지정 시 정보량에 따라 4~8장을 제안한다.
- 권장 흐름: 표지 훅 → 상황/문제 → 핵심 정보 → 지원 내용 → 기대 효과 → 행동 유도
- 각 카드의 핵심 메시지는 하나만 둔다.
- 금액·혜택형, 마감·신청형, 대상·자격형 중 정보 유형에 맞는 구성을 선택하고 [visual-design.md](visual-design.md)의 문구 예산과 3초 검사를 적용한다.
- 카드별 업로드 PNG, 무문자 원화, 확정 문구, 대체텍스트를 분리한다.
- 플랫폼 규격이 필요한 경우 게시 시점의 공식 자료를 다시 확인한다.

## `poster`

- 먼저 디지털용인지 인쇄용인지 구분한다.
- 디지털용은 정확한 픽셀 크기와 채널 최대 용량을 기록한다.
- 인쇄용은 재단 크기, 도련, 안전여백, DPI, 색상 프로필, 용지와 인쇄소 PDF 조건을 확인한다.
- 한눈에 보이는 제목, 핵심 혜택, 일정/대상/신청, 행동 유도의 위계를 사용한다.
- 캐릭터는 장식이 아니라 제목 또는 행동 유도의 시선 방향을 지원한다.

## `signage`

- `physical`과 `digital`을 분리한다.
- 실물 안내판은 실제 폭·높이, 설치 장소, 예상 시청 거리, 소재, 실내/실외, 조명과 출력 업체 사양을 확인한다.
- 디지털 사이니지는 화면 해상도, 가로/세로 방향, 안전영역, 재생 환경을 확인한다.
- 먼 거리에서 읽는 제목과 가까이 읽는 세부 정보를 분리한다.
- QR·연락처·방향 화살표는 실제 스캔·가독성 검사를 통과해야 한다.

## `web-banner`

- 채널별 실제 픽셀 규격, 모바일 크롭, 파일 용량과 투명 배경 허용 여부를 확인한다.
- 캐릭터 얼굴·가슴 로고와 핵심 문구가 모바일 크롭 안전영역 안에 있어야 한다.
- 여러 비율은 단순 축소가 아니라 초점·문자 줄바꿈·캐릭터 위치를 다시 배치한다.

## `social-post`

- Instagram·Facebook 피드의 단일 홍보 이미지와 일반 캐러셀에 사용한다. [단일 이미지](single-image-social.md)는 `delivery_form=single-image`, 이미지·copy.cards·채널 target_count를 각각 1로 맞춘다.
- 현재 3:4 세로, 4:5 호환, 1:1, 1.91:1 중 지면 프리셋을 선택한다.
- 복수 플랫폼은 각 지면의 비율·정보량·줄바꿈을 확인한다. 재단 단일 이미지 피드는 공용 1080×1080 PNG를 제작하고 양 채널에서 확인한다. 캐러셀은 선택한 지면과 장 순서를 기준으로 검수한다.
- 카드뉴스는 PNG 낱장과 함께 PDF 묶음·HTML 미리보기를 선택 제공할 수 있다.

## `social-story`

- Instagram·Facebook Story와 Reels 세로 원본에 사용한다.
- 9:16 캔버스를 기본으로 하되 상·하단과 우측 UI를 피해 제목, 얼굴, 가슴 `T/P`, CTA를 중앙 안전영역에 둔다.
- Reels 커버는 본편 세로 자산과 별도 프리셋으로 관리한다.

## `channel-message`

- 카카오톡 채널 관리자센터와 카카오모먼트 채널 메시지 광고를 먼저 구분한다.
- 기본 텍스트형, 와이드이미지형, 와이드리스트형, 캐러셀 피드·커머스형 중 실제 유형을 선택한다.
- 이미지 픽셀뿐 아니라 이미지 수, 비율 일관성, 메시지 글자 수, 버튼 수와 광고성 표시 확인 항목을 함께 기록한다.
- 업로드용은 JPG/PNG이며 PDF·HTML은 내부 검토본으로만 제공한다.

## 산출물 능력 표시

- `direct`: 현재 환경에서 실제 생성·조립·검증한 파일
- `tool-dependent`: 인쇄 PDF, CMYK, 특정 편집 원본처럼 외부 도구나 업체 검증이 필요한 파일
- `specification-only`: 제작 명세와 승인 이미지 자산만 제공하는 경우

도구가 없는 결과를 이름만 만들어 `direct`로 표시하지 않는다.

# 문자·말풍선 넘침 방지

웹툰·대화형 카드뉴스는 문자 크기·넘침과 함께 [대사 읽기 순서](dialogue-reading-order.md)를 검사한다. 한 대화 묶음의 풍선은 왼쪽→오른쪽 또는 위→아래 중 하나로 읽혀야 하며, 화자 꼬리와 대본을 알고 추측해서 순서를 보정하지 않는다.

한글을 별도 조판해도 글자를 박스 밖에 그리면 실패다. 2026-10-22 카드에서 고정 높이 124px 말풍선에 이름표와 두 줄 대사를 넣으면서 가로 폭과 카드 전체 하단만 검사해, 마지막 줄이 말풍선 하단 테두리에 걸렸다. 카드 전체 안전영역 안이라는 사실이 말풍선 안에 들어간다는 뜻은 아니다.

## 전체 이미지 생성의 문자 검수

`generation_method=whole-image`는 글자도 이미지 생성 도구에서 장면과 함께 만든다. 확정 문구 목록을 먼저 저장하고 생성본의 제목·숫자·단위·날짜·조건·문의·QR 안내를 빠짐없이 글자 단위로 대조한다. 전체 크기와 약 360px 폭에서 모든 영역을 읽고, 가장자리·말풍선·사물과의 접촉·잘림·필수조건 누락을 확인한다. OCR은 보조 수단이며 자동 추출 성공이 시각 검토를 대신하지 않는다. 오탈자나 넘침이 있으면 해당 오류와 보존할 요소를 명시해 이미지 생성 도구로 수정·재생성한다. 사용자 동의 없이 별도 문자 합성으로 바꾸지 않는다.

검수 기록에는 `method=generated-text-visual-comparison`, 실제 생성 파일의 해시, 확정 문구와 확인 결과, 확인한 크기와 한계를 남긴다. 생성 글꼴을 Paperlogy로 확정하거나 실제로 수행하지 않은 Canvas glyph 측정 완료를 선언하지 않는다. QR은 최종 파일과 축소본에서 별도로 해독한다.

## 별도 조판: 측정하고 나서 그리기

1. 최종 사용할 Paperlogy 파일을 실제 렌더러에 등록하고 로딩 성공을 확인한다. 대체 글꼴로 측정한 뒤 원래 글꼴로 내보내지 않는다.
2. 제목·대사·이름표·본문·출처 각각에 부모 영역과 위·아래·좌·우 여백을 지정한다. 1080px 카드의 대사 말풍선은 내부 24px 이상에서 시작하되 둥근 모서리·선 굵기·글꼴 모양에 맞게 더 확보한다. 꼬리, 테두리, 모서리는 글자를 놓는 영역이 아니다.
3. **폭과 높이를 모두 실측**한다. 글자 수나 `y+fontSize`만으로 통과시키지 않는다. 실제 glyph ascent/descent·좌우 돌출, 모든 줄의 행간, 이름표와 대사 간격, 마지막 줄 아래 여백을 계산한다. 명시적 줄바꿈이 있어도 각 줄의 폭과 전체 높이를 검사한다. `시·군`, 날짜·시간·금액, 이메일·전화번호의 읽기 단위는 보존한다.
4. 문장을 자연스럽게 다듬고 필요한 말풍선 높이와 폭을 확보한다. 부족하면 그림과 정보 영역을 재배치하거나 대사·컷·장을 나눈다. 옆 말풍선은 계산된 더 큰 높이에 맞출 수 있다. 새 높이에 맞춰 그림의 시작 위치도 내려서 겹침을 피한다.
5. 필수 조건을 지우거나 의미를 바꾸지 않는다. 작은 글꼴, 가로 압축, 말줄임, `clip`, `overflow:hidden`으로 넘친 부분을 숨겨서 통과시키지 않는다.
6. 글자와 부모 영역뿐 아니라 이웃 영역의 충돌도 확인한다. 제목–말풍선–그림–정보–출처–QR 사이에 겹침이 없어야 한다. 꼬리는 올바른 화자와 연결되고 얼굴·손·QR을 덮지 않는다.

## Canvas 도구

`scripts/safe_lettering.cjs`는 **호출자가 최종 출력에 쓰는 Canvas 2D context**를 받는다. 별도 Canvas 구현을 강제하지 않는다. `layoutText`는 실제 글자 경계로 줄바꿈·높이를 계산하고 고정 영역을 넘으면 예외로 출력을 차단한다. `layoutBubble`은 이름표·대사·여백을 포함한 필요한 높이를 반환한다. `height`를 생략하면 필요한 높이를 사용하며 지정한 높이가 작으면 실패한다.

```javascript
const {layoutBubble, drawBubble, writeReport} = require('<skill-root>/scripts/safe_lettering.cjs');
// ctx는 최종 PNG에 쓰는 context. 실제 Paperlogy 파일을 family 이름으로 등록한다.
const bubble = layoutBubble(ctx, {
  speaker: '테오', text: '주관기업과 수요처는 같은 시·군!',
  x: 48, y: 260, width: 476, fontFamily: 'Paperlogy', fontSize: 42
});
// bubble.box.height로 이웃 영역을 재배치한 다음 그린다.
drawBubble(ctx, bubble);
// 모든 제목·본문·이름표·대사·출처를 layoutText/drawText 경로로 조판한다.
// PNG 저장 후 실제 그린 텍스트 블록 전체를 기록한다.
writeReport(reportPath, finalPngPath, [bubble.label, bubble.body, ...otherTextLayouts]);
```

```powershell
python scripts/validate_lettering.py <card-01-lettering.json> <card-02-lettering.json>
```

내보낸 PNG의 해시가 바뀌거나 부모 영역 밖으로 글자가 나가면 실패한다. 모든 최종 카드에 보고서를 만들고 검사한다. 일부 텍스트만 보고하고 전체 문자 검증 완료라고 기록하지 않는다. 보고서·최종 PNG의 해시를 납품 manifest에 포함한다. HTML/SVG/PDF 등 다른 렌더러도 폰트 로딩 후 실제 문자 영역·부모 내부 영역·줄 높이를 측정하는 같은 원칙을 적용하고 Canvas용 보고서를 만든 것처럼 꾸미지 않는다.

자동 검사는 보고되지 않은 글자·화자 연결·주변 그림 가림까지 증명하지 않는다. 최종 100%와 약 360px 폭에서 **모든 장**을 시각 검수한다. 50%만 보고 테두리 접촉을 놓치지 않는다. 수정 후 다시 내보내고 해시·보고서·QR·미리보기를 갱신한다.

# 방명록 정렬 규칙

## 제목

방명록 제목은 회의록에서 확정한 전체 회의명을 그대로 쓴다. 지출증빙서의 `지출항목`과 공백·괄호까지 같아야 한다. 양식 제목이 여러 필드와 장식 기호로 구성되어 있으면 제목 문단 전체를 확정 회의명으로 교체해 빈 `「」`, `『』`, `[]`, `【】`가 남지 않게 한다.

## 기본 순서

기안문의 개인별 명단을 우선하고 별도 명단은 보완 자료로 쓴다. 둘 다 없으면 이름을 추정하지 않고 방명록을 보류한다. 불확실한 표기는 빨간색, 사용자가 정정한 표기는 검정색으로 한다. 빨간색 표시는 `extend_guestbook.py`가 처리하지 않으므로 해당 값이 있으면 생성 후 별도로 적용하거나 먼저 사용자에게 확인받는다.

1. 외부 기관 참석자를 먼저 배치한다.
2. 외부 기관끼리는 원자료의 기관 묶음 순서를 유지한다.
3. 각 기관 안에서는 제공된 직급 순서를 쓰고, 없으면 상위 직급부터 배치한다.
4. 포항테크노파크 소속을 전체 목록의 마지막에 배치한다.
5. 같은 기관·같은 직급은 원자료 순서를 유지한다.

`포항테크노파크`, `포항TP`, `(재)포항테크노파크`는 같은 그룹으로 묶는다. 계열사·참여기관·출연기관은 자료에 적힌 소속을 따르며 자동으로 합치지 않는다. 직급 비교가 애매하면 원자료 순서를 유지하고 정렬 기준을 보고한다.

## 서명란

서명란은 빈칸으로 출력한다. 참석자 본인이 직접 서명한다. 글자·이미지·도형을 넣지 않는다.

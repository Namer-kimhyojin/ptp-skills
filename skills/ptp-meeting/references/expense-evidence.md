# 지출증빙서 작성 규칙

## 건별 처리

영수증 또는 카드매출전표 한 장을 하나의 지출증빙 건으로 본다. 한 영수증이 PDF 여러 페이지에 걸쳐 있으면 하나의 건이고, 페이지별로 분리된 영수증은 각각 별도 건이다.

## 작성 전 확인

다음에 해당하면 자동으로 확정·제외하지 말고 사용자에게 내용을 보여주고 확인한다.

- 중복 의심: 승인번호가 같거나, 상호·거래일시·금액이 같은 영수증 (승인번호는 대조에만 쓰고 문서에 옮기지 않는다)
- 취소·환불·부분취소 표시가 있는 영수증
- 영수증 거래일이 회의일과 다른 경우
- 영수증 금액과 기안문 금액이 다른 경우

## 필드 매핑

| 양식 필드 | 입력 출처 | 처리 |
|---|---|---|
| 지출항목 | 회의록에서 확정한 전체 회의명 | 방명록 제목과 공백·괄호까지 동일하게 기입 |
| 예산과목 | 기안문 | 기안문 표기를 유지, 임의 생성 금지 |
| 사용금액 | 영수증 총액 | 숫자·통화 표기를 확인 후 입력 |
| 사용처 | 영수증 가맹점명 | 상호명을 원문대로 입력 |
| 사용일자 | 영수증 거래일시 | 날짜만 필요하면 날짜만 입력 |
| 증빙 영역 | 해당 영수증 | 바깥 여백을 제거한 영수증 영역 이미지 배치 |

증빙내역은 `₩사용금액 (사용처_사용일자)` 형태를 기본으로 하되 양식의 기존 표기를 유지한다. 읽히지 않는 금액은 추정하지 않고 확인 필요로 둔다.

## 합본

모든 건을 한 HWPX 파일에 넣고 각 건은 새 페이지에서 시작한다. 바깥 여백과 스캔 테두리만 잘라 내고 상호·거래일시·금액·확인문구는 잘리지 않게 한다. 이미지는 비율을 유지해 셀 안에 맞추고, 판독이 어려울 만큼 작아지면 알린다. 영수증이 없는 지출 건은 추가하지 않는다.

# 입력·출력 계약

## 권장 입력 묶음

```text
meeting_case/
  draft.*          # 내부 기안문 또는 기안문 이미지
  receipts/        # 영수증 PDF·PNG·JPG, 여러 장 가능
  attendees.*      # 기안문에 개인별 명단이 없을 때 필수
  notes.*          # 선택: 실제 회의 메모·결과 자료
  options.txt      # 선택: 간략히, 기관명 표기, 출력 파일명 등
```

기안문과 별도 명단이 충돌하면 별도 명단이 최신이라는 확인이 없는 한 기안문을 기준으로 하되 충돌을 보고한다. 개인별 명단이 어디에도 없으면 방명록을 만들지 않고 소속, 직위, 성명, 외부·내부 구분을 요청한다. 회의록과 지출증빙서의 생성 가능 여부는 따로 판단한다.

## 산출물

```text
outputs/
  회의록_<회의명>.hwpx
  방명록_<회의명>.hwpx            # 서명란 빈칸
  방명록_<회의명>.validation.json
  지출증빙서_<회의명>_전체.hwpx
```

파일명에 쓸 수 없는 문자는 제거하고 회의명을 과도하게 줄이지 않는다. DOCX, HWP, PDF를 요청받으면 변환 가능 여부와 변환 후 시각 검증 여부를 구분해 보고한다.

## 미확정 정보 처리

- 금액·날짜·시간·인원은 추정값으로 채우지 않는다.
- 영수증과 기안문의 금액이 다르면 각 금액의 출처를 구분해 표시한다.
- 외부·내부 구분이 불명확한 참석자는 확인을 요청한다.
- 직급 체계가 기관마다 다르면 기관 내 제공 순서 또는 원자료 순서를 우선한다.

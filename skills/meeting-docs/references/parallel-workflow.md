# 문서 세트 병렬 생성

## 적용 조건

문서 둘 이상을 함께 만들고 서브 에이전트를 쓸 이점이 있을 때만 적용한다.

## 선행 작업

메인 에이전트가 원자료를 직접 읽고 다음 값을 하나의 정규화 데이터로 확정한다.

- 확정 전체 회의명 (방명록 제목, 지출증빙서 `지출항목`에 공통 사용)
- 일시·장소·참석자·내부/외부 구분
- 승인 예정액·실제 결제액·사용처·예산과목
- 미확정 값과 문서별 공란 처리

서브 에이전트는 정규화 데이터를 읽기 전용으로 쓰고 이름·금액·제목을 다시 해석하지 않는다.

## 배정과 병합

회의록, 방명록(서명란 빈칸), 지출증빙서를 각각 `work/<run-id>/minutes`, `guestbook`, `expense`에서 만든다. 각 담당은 다른 담당의 파일과 원자료를 수정하지 않는다.

모두 끝난 뒤 메인 에이전트가 모아 다음을 확인한다.

- 세 문서의 참석자·일시·장소·금액이 정규화 데이터와 일치
- 회의명, 방명록 제목, `지출항목`이 동일
- 방명록 서명란이 모두 빈칸
- 각 HWPX 구조 검사 통과

한 문서만 실패하면 그 문서만 다시 만든다.

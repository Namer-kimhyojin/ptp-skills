# 공고레이더 (announcement-radar) — 직원용 안내

정부·전담기관·지자체의 신규 사업공고와 기술수요조사·RFP 사전공개를 찾아
(재)포항테크노파크 기준 적합도(0~100점)를 매기고, 원문 링크를 바로 누를 수 있는 **HTML 브리핑**으로 만들어 주는 Claude 스킬입니다.

## 설치

**Claude 앱(웹·데스크톱)**
1. 설정 → 기능(Capabilities)에서 코드 실행과 웹 검색이 켜져 있는지 확인합니다.
2. 같은 화면의 스킬 항목에서 `announcement-radar.zip`을 업로드합니다.

**Claude Code**
zip을 풀어 `announcement-radar` 폴더를 `%USERPROFILE%\.claude\skills\` 아래에 둡니다.
(최종 경로: `C:\Users\<사용자>\.claude\skills\announcement-radar\SKILL.md`)

파이썬 3.9 이상이 있으면 점수 검산과 HTML 생성이 자동으로 됩니다. 추가 패키지는 필요 없습니다.

## 이렇게 말하면 됩니다

| 하고 싶은 일 | 예시 |
| --- | --- |
| 전체 스캔 | "공고레이더 돌려줘", "이번 주 우리가 주관할 만한 공고 찾아줘" |
| 사전조사만 | "기술수요조사 나온 거 있어?" |
| 한 기관만 | "KETEP 공고만 다시 봐줘" |
| 소스 목록 | "공고 수집 소스 목록 보여줘" |
| 소스 점검 | "소스 점검해줘" — 접속 안 되는 게시판을 찾아 새 주소를 제안합니다 |
| 소스 추가 | "포항강소특구육성센터 공고 게시판 소스로 추가해줘" (기관명만 말해도 주소를 찾아 확인 후 추가) |
| 소스 삭제 | "KOCCA 소스 삭제해줘" — 되돌리기: "KOCCA 소스 복원해줘" |
| 설정 | "키워드에 스마트팜 추가", "예산 3억 미만은 감점", "data.go.kr 인증키 등록" |

스캔 중 포털에서 찾은 공고가 등록되지 않은 기관 사이트에 있으면, 그 기관 게시판을 확인해 소스로 **자동 추가**합니다(한 번에 최대 3개). 추가된 소스는 브리핑 "수집 현황"에 표시되니, 필요 없으면 삭제하라고 말하면 됩니다.

## 결과물

작업 폴더의 `공고레이더/` 아래에 저장됩니다.

- `브리핑_YYYYMMDD.html` — 브라우저로 여는 결과물. 공고명을 누르면 원문이 새 탭으로 열리고, 위쪽 검색창으로 기관·분야·플래그를 걸러 볼 수 있습니다. 처음 본 공고에는 NEW 표시가 붙습니다.
- `sources.json` · `history.json` · `config.json` — 내 소스 목록, 본 공고 이력, 설정

Claude 앱(웹)에서는 대화가 끝나면 작업 폴더가 사라집니다. 소스를 추가·삭제했다면 `sources.json`을 내려받아 두었다가 다음 대화에 첨부하세요. 프로젝트 기능을 쓰면 프로젝트 파일로 올려 두면 됩니다.

브리핑 화면 예시는 `assets/briefing_example.html`에 있습니다 (2026-11-26 시범 스캔 기준).

## 적합도 기준 요약

| 항목 | 배점 | 내용 |
| --- | --- | --- |
| 자격 게이트 | 탈락 | G1 비영리 신청 불가 · G2 지역 요건 · G3 타 기관·기존 수행자 지정 |
| A 주관 적격성 | 25 | TP 주관 명시 25 / 비영리 주관 가능 20 / 참여기관만 12 / 미상 8 |
| B 분야·키워드 | 25 | 바이오·에너지·SW·AI·철강·제조 일치도 + 키워드 |
| C 과제 유형 | 20 | 기술개발 20 > 사업화 15 > 운영·관리 12 > 인력양성 10 > 네트워킹 5 |
| D 예산 규모 | 15 | 과제당 금액이 클수록 높음 |
| E 마감 여유 | 15 | D-30 이상 15 … D-2 이하 0 |
| F 실행 난이도 | −5 | 해외 기관 참여 필수 |

70점 이상 즉시 검토, 40~69점 참고. 마감 7일 이내인데 자격·분야·유형이 최상위권이면 점수와 관계없이 "마감 임박" 칸에 올립니다.
자세한 기준은 `references/scoring.md`, 기관 기준값은 `references/org-profile.md`에 있습니다.

## 공공데이터포털 인증키 (선택)

e나라도움·나라장터는 웹 화면을 자동으로 읽을 수 없어 공공데이터포털(data.go.kr) API가 필요합니다.
data.go.kr에서 개인 인증키를 발급받아 "data.go.kr 인증키 등록"이라고 말하면 `config.json`에 저장됩니다. 키는 개인별로 받아 쓰고, 다른 사람과 공유하지 마세요.

## 주의

브리핑은 수집 시점의 공고문 문구로 판정한 결과입니다. 신청 전에 원문에서 신청 자격과 마감을 반드시 다시 확인하세요.

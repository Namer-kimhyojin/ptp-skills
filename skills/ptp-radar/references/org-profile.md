# 기관 프로필 — (재)포항테크노파크 (org-profile.md)

채점 기준값이다. 다른 기관이 이 스킬을 쓰려면 이 파일만 그 기관에 맞게 바꾸면 된다.
작업 폴더 `config.json`의 `extra_keywords`·`extra_fields`는 아래 값에 **더해서** 쓴다.

## §1. 조직 개요

| 항목 | 내용 |
| --- | --- |
| 법적 형태 | 비영리 재단법인, 포항시 출자·출연기관 |
| 설립 | 2000년 출연 시작. 포항시·포스코·포스텍·경상북도 등이 공동 출연. 정부 주도가 아닌 기초지자체·민간기업 주축으로 만든 TP |
| 지배구조 | 이사장: 포항시장 |
| 법적 지위 | 산업기술단지 특례법상 사업시행자 — TP 한정 공모의 주관기관 자격 근거 |
| 경영 | 재정자립도 100% 이상(2020~2023), 전국 TP 경영실적평가 A등급 4년 연속(2024년 이사회 보고 기준) |
| 지역 기반 | 이차전지 특화단지(2023), 바이오 특화단지(2024), 수소특화단지(2024.11), 강소연구개발특구(TP 사업화지구), 벤처기업육성촉진지구 |
| 주요 조직 예 | 경북AI혁신본부(동북권 ICT콤플렉스), 이차전지산업팀, 해양산업팀 등 |

**채점에 쓰는 핵심 사실**
- 영리기업이 아니다 → 기업만 신청 가능한 공고는 G1.
- 비영리 재단법인 + 특례법상 사업시행자 → "비영리기관·공공기관·기업지원기관 주관 가능", "테크노파크 주관" 공고에 해당.
- 포항(경북, 비수도권)에 있다 → 지역 요건은 §5로 판정.
- 역할: ① 중앙부처·전담기관 공모의 주관·참여기관, ② 포항시·경북도 위탁사업 수행기관, ③ 지역기업 지원사업 기획·공고 주체.

# 재단 SNS 게시 기본값

`config/publication-defaults.json`을 읽는다. 재단 공식 SNS 최종 제작은 양쪽 채널 검수 후 즉시 공개가 기본 선택이다. 재단 계정 식별자는 `config/social-accounts.json`을 사용한다. 지정 채널·시각·게시 보류, 초안, 내부 검토·파일만 요청을 우선한다. 인쇄물·자료 조사·캡션만·캐릭터 등록·스킬 시험은 그 요청 범위까지 처리한다.

1. 게시 범위와 캐릭터가 이미 정해졌으면 제작한다. 사용자 요청이나 해당 작업을 포함하는 기존 위임에 “게시”, “등록”, “자동 게시”가 있고 채널 미지정이면 설정된 재단 인스타그램·페이스북 양쪽을 사용한다.
2. 정식 SNS 작업에서 게시 범위가 아직 정해지지 않았으면 캐릭터 선택과 한 번에 받는다. 예시 선택지는 **테오·피오로 제작해 두 채널에 게시(기본)**, **캐릭터 없이 제작해 두 채널에 게시**, **파일만 제작**이다. 다른 저장 세트는 목록으로 함께 보여주고 “피오만 + 양쪽 게시”처럼 한 번에 지정할 수 있게 한다. 캐릭터가 이미 정해졌으면 고정하고 **검수 후 두 채널 게시(기본)** 또는 **파일만 제작**의 범위만 받는다.
3. 실제 게시 요청, 명시적으로 선택한 게시 옵션 또는 기존 위임을 `publication.authorization_evidence`에 기록한다. 검수 후 실제 제출할 채널과 계정만 `publication.targets`에 넣는다. 이 근거로 `requested=true`, `authorized=true`를 설정한다. 캐릭터 이름만 답했거나 무응답이면 확정 가능한 제작을 계속한다. 제출은 게시 범위 근거가 생기면 진행한다.
4. 게시 범위가 확정된 작업은 `publication`으로 검사한다. 채널별 계정·게시 권한·게시 이력·미리보기와 원문 접수기간(사업공고)을 확인한 뒤 자동으로 제출한다. 이미 완료된 채널은 기존 주소를 사용하고 결과가 불명확한 채널은 원래 제출부터 확인한다. [계정 설정·게시·재개](social-publishing.md)를 적용한다.

공식 SNS 발행 담당자가 여러 명이면 같은 제작·게시 장부와 원본 패키지를 쓰는 승인된 발행 환경에서 진행한다. 설치본별 로컬 장부는 자동 동기화되지 않는다. 처음 설치할 때 기존 장부를 교체하지 않으며 원격의 게시·예약·초안도 직접 대조한다.

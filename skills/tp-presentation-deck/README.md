# tp-presentation-deck (포항테크노파크 발표자료 스킬)

자료를 주고 "발표자료 만들어줘"라고 하면 A4 가로 발표자료를 **단일 HTML 파일**로 만든다.
전체 화면 발표 보기, 편집 모드(글 서식·이동·크기·복제·삭제), 인쇄/PDF를 지원한다.

## 설치
- Claude(웹·데스크톱): 설정 → 기능(Capabilities) → 스킬 → 스킬 업로드에서 이 zip을 올린다.
- Claude Code: `tp-presentation-deck` 폴더를 `~/.claude/skills/`(개인) 또는 프로젝트의 `.claude/skills/`에 넣는다.

## 사용
"이 자료로 발표자료 제작해줘" + 파일 첨부. 결과 HTML을 브라우저로 열어 `발표 보기`(전체 화면) 또는 `편집 모드`를 쓴다.
`examples/sample-deck-edit-mode.html`은 완성 모습을 보여 주는 5쪽 샘플이다.
`examples/layout-catalog.html`은 표지 3종(기본형·간결형·띠형), 목차 쪽, 추가 쪽 유형(P~X), 밀도 단계 표시 예시다(수치는 가상).

## 구성
- SKILL.md: 스킬 본문(CSS·JS·쪽 유형·밀도 기준·검수 절차)
- assets/: 재단 CI 로고(가로형 한글·한영·영문 약식, 세로형 한영 공식, 심볼, 각 흰색판). 압축을 풀 때 SKILL.md와 같은 폴더 구조를 유지해야 로고가 들어간다
- examples/: 샘플 덱(5쪽, 간결형 표지)과 쪽 유형 예시(14쪽, 표지 3종·목차·P~X)

## 요청 양식 (복사해서 쓰기)

```text
첨부한 기본자료로 발표자료 제작해줘.

사업 또는 주제 =
발표 유형과 목적 =
청중과 발표 후 필요한 판단·행동 =
기준일과 집계기간 =
반드시 포함할 내용과 강조할 메시지 =
사용할 자료와 자료 간 우선순위 =
크기(A4·16:9)·발표시간·쪽수 =
기관 서식·디자인·출처 표시·공개 범위 =
```
비워 둔 항목은 스킬이 한 번에 묻거나 기본값으로 정한다.

# 포항테크노파크 업무 스킬

포항테크노파크(포항TP) 직원이 AI 도우미(Claude, ChatGPT, Gemini 등)에게 업무를 맡길 때 쓰는 스킬 모음입니다. 스킬은 작성 요령과 양식을 AI에게 미리 알려 주는 폴더이며, 스킬을 쓰기만 하는 직원은 GitHub 계정이 필요 없습니다.

## 사이트

- 스킬 폴더의 `catalog.yaml`은 사이트 표시용 정보이며, 배포 zip에는 들어가지 않습니다.
